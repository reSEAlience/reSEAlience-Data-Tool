# reSEAlience-Data-Tool

# how to set up locally 
git clone <repository-url>
cd reSEAlience-Data-Tool/frontend
npm ci      
npm run build


## How to Run in Android Studio
Make sure directory is in frontend
* npm run build
* npx cap sync android
* npx cap open android

From Android Studio Select device via USB cable then run
* to connect device: click build number 7 times -> open developer options -> turn on USB debugging
